## Problem Statement

Sajid and Hamza are waiting for their next class at 7 th floor of AUST. They are bored at RedX and hence they start to play a game.

Hamza loves mathematics and he loves $0$ as a number too much. For that reason, he gives Sajid an array of numbers and tells him to multiply the numbers together.

Hamza asks Sajid to tell him the number of trailing zeroes of the multiplication. Sajid also needs to tell if the multiplication is divisible by the floor number of the next class or not.

Sajid is unable to figure out, so he needs help. Help him!

## Input

The first line contains the number of test cases $T(1≤T≤10)$.

The first line of each test case contains $N(1≤ N ≤ 10^5)$- the size of the array.

The second line of each test case contains $N$ integers $a_1,a_2,a_3,...,a_n(1≤a_i≤10^9)$.

It is guaranteed that the sum of $N$ over all test cases does not exceed $10^6$.

## Output

For each test case: output Z and S. Here Z is the number of trailing zeroes after multiplication and S is 1 if the multiplication is divisible by the floor number of the next class, otherwise 0.
