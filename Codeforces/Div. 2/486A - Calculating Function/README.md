For a positive integer `n` let's define a function `f`:

`f(n) = - 1 + 2 - 3 + .. + ( - 1)ⁿn` 

Your task is to calculate `f(n)` for a given integer `n`.

## Input

The single line contains the positive integer `n` (`1 ≤ n ≤ 10¹⁵`).

## Output

Print `f(n)` in a single line.

## Examples

**Example 1:**

```
4

```

**Output 1:**

```
2

```

**Example 2:**

```
5

```

**Output 2:**

```
-3

```

## Note

`f(4) = - 1 + 2 - 3 + 4 = 2`

`f(5) = - 1 + 2 - 3 + 4 - 5 = - 3`
